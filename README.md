# 📚 Paper Reading Notes

Academic paper reading notes and summaries.

## Structure

```
paper-reading/
├── <topic>/
│   ├── notes/          # Markdown summaries & reviews
│   │   ├── survey.md   # Topic overview/survey
│   │   ├── paper1.md   # Individual paper notes
│   │   └── ...
│   └── papers/         # Original PDFs
│       ├── paper1.pdf
│       └── ...
├── README.md
└── TEMPLATE.md         # Template for paper notes
```

## Topics

| Topic | Description | Papers |
|-------|-------------|--------|
| [world-models](./world-models/) | World models, cognitive AI, predictive learning | WIP |

## How to Use

1. Create a new topic directory: `mkdir -p <topic>/{notes,papers}`
2. Add PDF papers to `<topic>/papers/`
3. Write notes in `<topic>/notes/` using the template

## Note Template

See [TEMPLATE.md](./TEMPLATE.md) for paper note template.
