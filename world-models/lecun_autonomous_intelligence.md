## 这篇论文尝试解决什么问题？

### 背景：当前 AI 的根本局限

尽管大语言模型取得了惊人进展，但当前 AI 仍然：

1. **学习效率低**：需要海量数据，远超人类和动物
2. **缺乏推理能力**：无法真正"思考"和规划
3. **缺乏世界模型**：不理解物理世界如何运作
4. **缺乏层次抽象**：无法在多个时间尺度上推理

### 核心问题

> 如何构建能像人类和动物那样高效学习、推理和规划的自主智能体？

LeCun 的回答：需要**可配置的预测性世界模型 (Configurable Predictive World Model)**。

## 解决思路是什么？

### 1. 提出的架构：JEPA + World Model

LeCun 提出了一个完整的认知架构：

```
┌─────────────────────────────────────────────────────────┐
│                    Configurator                          │
│        (配置世界模型以执行特定任务)                        │
├─────────────────────────────────────────────────────────┤
│                                                          │
│  ┌─────────┐     ┌─────────────────┐     ┌──────────┐   │
│  │ Percept │────▶│  World Model    │────▶│  Actor   │   │
│  │ (感知)  │     │ (世界模型-预测)   │     │ (动作)   │   │
│  └─────────┘     └─────────────────┘     └──────────┘   │
│                          │                               │
│                    ┌─────▼─────┐                        │
│                    │   Cost    │                        │
│                    │ (内在动机) │                        │
│                    └───────────┘                        │
│                                                          │
├─────────────────────────────────────────────────────────┤
│               Short-term Memory                          │
│           (短期记忆/工作记忆)                              │
└─────────────────────────────────────────────────────────┘
```

### 2. 核心组件

#### 世界模型 (World Model)
- 预测感知输入的未来状态
- 给定当前状态和动作，预测下一个状态
- **在抽象表示空间中预测**，而非像素空间

#### JEPA (Joint Embedding Predictive Architecture)
- **核心创新**：在嵌入空间中预测，而非直接预测原始输入
- 避免生成模型需要建模所有细节的问题
- 只预测**相关信息**，忽略不可预测的噪声

```
传统生成模型: x_t → predict → x_{t+1} (像素)
JEPA:        enc(x_t) → predict → enc(x_{t+1}) (嵌入)
```

#### 分层架构 (Hierarchical Architecture)
- 不同抽象层次的表示
- 低层：快速、细粒度（毫秒级）
- 高层：慢速、抽象（秒/分钟/小时级）

### 3. 关键思想

#### 自监督学习 vs 强化学习

LeCun 明确批评了纯 RL 方法：
- RL 样本效率极低
- 奖励信号过于稀疏
- 不适合学习世界模型

**主张**：使用**自监督学习**从观测数据中学习世界模型

#### 内在动机 (Intrinsic Motivation)

动机不应该是外部奖励，而是：
- 好奇心
- 预测误差最小化
- 信息增益最大化

#### 推理即规划

"推理"本质上是在世界模型中进行**心理模拟**：
- 预测不同动作序列的结果
- 选择最优动作
- 这就是"System 2 思考"

## LeCun 的核心论点

1. **生成模型是错误的路**：预测像素太难、太浪费
2. **RL 效率太低**：不应该是主要学习范式
3. **自监督是关键**：从大量无标签数据学习
4. **世界模型是必须的**：推理 = 在模型中模拟
5. **分层抽象是必须的**：不同时间尺度的规划
