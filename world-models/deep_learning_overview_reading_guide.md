## 🔑 核心概念：Credit Assignment Path (CAP)

Schmidhuber 定义"深度"的方式：

> **深度 = 信用分配路径 (CAP) 的长度**

- 信息从输入到输出经过多少个**可学习的变换**
- CAP 越长 → 越"深" → 越难训练
- 深度学习的本质问题：如何在很长的 CAP 上有效地分配 credit

---

## 🎪 四大反复出现的主题 (Section 4)

### 1️⃣ 动态规划 (DP)
- 反向传播本质上是 DP
- 强化学习中的 value iteration 也是 DP
- **核心思想**: 把大问题分解成子问题

### 2️⃣ 无监督学习辅助监督学习
- 先用 UL 学习数据的压缩表示
- 再用 SL 在这个表示上学习
- **核心思想**: 降低问题的"深度"

### 3️⃣ 层次化表示学习
- 从底层特征到高层抽象
- 自动学习特征层级
- **核心思想**: 抽象 = 压缩

### 4️⃣ 奥卡姆剃刀 / 最小描述长度 (MDL)
- 简单的模型更好
- 压缩 = 理解
- **核心思想**: 智能 = 压缩能力

## 📅 监督学习历史时间线 (Section 5 精华)

### 1940s-1960s: 萌芽期
- **1943**: McCulloch-Pitts 神经元
- **1958**: 感知机 (Rosenblatt)
- **1965**: GMDH —— 第一个真正的深度网络！

### 1970s-1980s: 反向传播时代
- **1970**: 自动微分 (Linnainmaa)
- **1974**: 反向传播用于控制 (Werbos)
- **1979**: Neocognitron —— CNN 的前身
- **1986**: BP 普及 (Rumelhart, Hinton, Williams)
- **1989**: BP 用于 CNN (LeCun)

### 1990s: 深度学习的"冬天"
- **1991**: 梯度消失问题被正式研究
- **1991**: 历史压缩 / RNN 栈
- **1997**: **LSTM** 诞生 ⭐

### 2000s: 复兴
- **2006**: DBN / 深度信念网络 (Hinton)
- **2006**: GPU 加速开始流行

### 2010s: 爆发
- **2011**: GPU-CNN 超越人类视觉
- **2012**: ImageNet 竞赛大突破 (AlexNet)

## 💡 Schmidhuber 的核心观点

1. **深度学习不是新东西** —— 很多核心思想在 1960s-1990s 就有了

2. **智能的本质是压缩** —— 
   > "Compression = Prediction = Understanding"

3. **历史 credit 分配很重要** —— 他花大量篇幅追溯每个想法的真正起源

4. **LSTM 是他最自豪的贡献** —— 论文多次强调 LSTM 解决了梯度消失问题
