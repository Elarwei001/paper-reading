# Learning Laws from Phenomena: Research Landscape

**Topic**: Which institutions and researchers are working on learning underlying laws/rules from observable phenomena?  
**Date**: 2026-02-19

## Overview

This is a frontier research direction that bridges several fields:
- Causal inference meets deep learning
- Physics-informed machine learning
- Neuro-symbolic AI
- Structured representation learning
