# Towards Causal Representation Learning

**Paper**: Towards Causal Representation Learning  
**Authors**: Bernhard Schölkopf†, Francesco Locatello†, Stefan Bauer⋆, Nan Rosemary Ke⋆, Nal Kalchbrenner, Anirudh Goyal, Yoshua Bengio  
**Year**: 2021  
**Venue**: Proceedings of the IEEE (Special Issue on AI/ML)  
**arXiv**: [2102.11107](https://arxiv.org/abs/2102.11107)

---

## 这篇论文尝试解决什么问题？

### 背景：两个领域的交汇

**机器学习** 和 **因果推断** 长期独立发展：

| 机器学习 | 因果推断 |
|---------|---------|
| 数据驱动 | 模型驱动 |
| 预测 P(Y\|X) | 预测干预效果 |
| i.i.d. 假设 | 处理分布变化 |
| 从原始数据学习 | 假设因果变量已知 |

### 核心问题

本文试图回答两个方向的问题：

1. **因果推断 → 机器学习**：因果思维如何帮助解决 ML 的核心挑战（鲁棒性、迁移、泛化）？

2. **机器学习 → 因果推断**：如何从原始观测数据中**发现因果变量**？（因果表征学习）

---

## 解决思路是什么？

### 1. 因果建模的三个层次

| 层次 | 能回答的问题 | 例子 |
|-----|-------------|-----|
| **物理模型** (微分方程) | 完整动力学 | d**x**/dt = f(**x**) |
| **因果模型** (SCM) | 干预和反事实 | do(X=x) → Y=? |
| **统计模型** | 相关性预测 | P(Y\|X) |

### 2. Issue 1: 鲁棒性 (Robustness)

**问题**：深度模型对分布偏移敏感（模糊、噪声、对抗攻击）

**因果视角**：
- 统计关联在分布变化时会失效
- 因果机制更加**不变**
- 数据增强本质上是在模拟干预

### 3. Issue 2: 可重用机制 (Reusable Mechanisms)

**问题**：如何快速迁移到新任务？

**因果视角**：
- 世界由**模块化的因果机制**组成
- 大多数机制在不同任务中保持不变
- 只需要适应少数改变的机制

### 4. 独立因果机制原则 (ICM Principle)

**核心假设**：

> 生成过程的因果机制是**独立的**，不会相互透露信息。

**含义**：
- P(效果|原因) 不依赖于 P(原因)
- 改变一个机制不会影响其他机制
- **稀疏机制偏移** (Sparse Mechanism Shift)：分布变化通常只影响少数机制

### 5. 因果发现方法概述

**从观测数据**：
- 条件独立性测试 (PC, FCI 算法)
- 基于得分的方法 (BIC, MDL)
- 双变量方法 (ANM, IGCI)

**从干预数据**：
- 随机对照实验
- 多环境学习

### 6. 因果表征学习 (核心贡献)

**问题**：大多数因果方法假设变量已给定，但现实中只有原始数据。

**挑战**：
- 从图像/视频/文本中发现潜在因果变量
- 学习满足因果假设的表示空间
- 可识别性问题

**方向**：
- 利用时间结构
- 利用干预
- 结合物理先验

## 效果如何？

### 对 ML 实践的启示

| ML 实践 | 因果解释 |
|--------|---------|
| **数据增强** | 模拟干预，学习不变特征 |
| **领域适应** | 适应机制变化，保留不变机制 |
| **半监督学习** | 反因果场景有效（Y→X） |
| **预训练** | 学习可重用的因果机制 |
| **自监督学习** | 发现因果结构的潜力 |

### 强化学习的因果视角

- 动作 = 干预
- 模型学习 = 学习因果机制
- 反事实推理对规划至关重要

## 还有哪些待解决的问题？

### 1. 因果表征学习的可识别性

> 什么条件下可以从观测数据中唯一恢复因果变量？

- 目前的可识别性结果需要强假设
- 需要更实用的条件

### 2. 与深度学习的整合

- 如何在神经网络中编码 ICM 先验？
- 架构设计的因果归纳偏置？
- 端到端的因果发现？

### 3. 非线性 ICA 与因果变量发现

- 非线性 ICA 的可识别性与因果发现的关系
- 利用辅助信息（时间、标签）

### 4. 大规模因果推断

- 如何扩展到高维、复杂系统？
- 计算效率

### 5. 评估和基准

- 如何评估学习到的因果结构？
- 缺乏统一的基准数据集

## 关键概念速查

| 概念 | 含义 |
|-----|------|
| **ICM** | Independent Causal Mechanisms，独立因果机制 |
| **Sparse Mechanism Shift** | 分布变化只影响少数机制 |
| **Causal Representation Learning** | 从原始数据发现因果变量 |
| **Identifiability** | 能否唯一确定因果结构 |
| **Anti-causal** | 预测原因给定效果（Y→X 方向） |
