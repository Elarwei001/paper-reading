# Causality for Machine Learning

**Paper**: Causality for Machine Learning  
**Authors**: Bernhard Schölkopf  
**Year**: 2019  
**Venue**: Festschrift for Judea Pearl (ACM, 2022)  
**arXiv**: [1911.10500](https://arxiv.org/abs/1911.10500)

---

## 这篇论文尝试解决什么问题？

### 背景：机器学习的根本局限

当前的机器学习方法在 **i.i.d.（独立同分布）** 假设下表现优异，但在以下场景中往往失败：

1. **分布偏移 (Distribution Shift)**：训练分布与测试分布不同
2. **迁移学习 (Transfer)**：从一个问题泛化到另一个问题
3. **对抗攻击 (Adversarial Attacks)**：微小的、人眼不可见的扰动导致错误分类
4. **干预推理 (Intervention Reasoning)**：预测"如果我们改变某个变量会发生什么"

### 核心问题

> 为什么统计模型在 i.i.d. 设置下有效，却无法处理真实世界中的变化？

**答案**：统计模型只捕捉**相关性 (correlations)**，而非**因果机制 (causal mechanisms)**。

---

## 解决思路是什么？

### 1. 从统计模型到因果模型

| 模型类型 | 能做什么 | 不能做什么 |
|---------|---------|----------|
| 统计模型 | 预测 P(Y\|X) | 预测干预效果、处理分布偏移 |
| 因果模型 | 预测干预效果、跨分布泛化 | 需要更强假设 |
| 物理模型 | 完整描述机制 | 需要领域专家设计 |

### 2. 结构因果模型 (SCM)

将世界描述为一组**赋值方程**：

```
Xᵢ := fᵢ(PAᵢ, Uᵢ)
```

其中：
- `PAᵢ` = Xᵢ 的父节点（直接原因）
- `Uᵢ` = 独立噪声
- `fᵢ` = 因果机制

### 3. 独立因果机制原则 (ICM Principle)

**核心洞察**：因果机制是**模块化且独立**的。

- P(效果|原因) 不依赖于 P(原因) 的变化
- 改变一个机制不会影响其他机制

**实际意义**：
- 相关性会随分布变化而改变
- 因果机制在不同环境中保持**不变**

### 4. 因果分解 vs 统计分解

给定联合分布 P(X₁, ..., Xₙ)，有很多种分解方式：

**因果分解（Disentangled）**：
```
P(X₁, ..., Xₙ) = ∏ᵢ P(Xᵢ | PAᵢ)
```

**统计分解（Entangled）**：
```
P(X₁, ..., Xₙ) = ∏ᵢ P(Xᵢ | Xᵢ₊₁, ..., Xₙ)
```

只有因果分解的各因子是**独立且可重用**的。

## 效果如何？

### 对机器学习的启示

1. **鲁棒性**：基于因果机制的预测器对分布偏移更鲁棒
2. **迁移学习**：因果模型可以更快适应新任务
3. **数据增强的本质**：实际上是在模拟干预
4. **半监督学习**：P(Y|X) 独立于 P(X) → 无标签数据对预测没有直接帮助（"半监督学习悖论"）

### 双变量问题的突破

即使只有两个变量，也可以通过以下方式识别因果方向：
- 独立性约束
- 函数类假设（如加性噪声模型）
- 信息几何方法

## 还有哪些待解决的问题？

### 1. 因果表征学习 (Causal Representation Learning)

**最核心的开放问题**：

> 如何从低层观测（像素、文本）中发现高层因果变量？

目前的因果推断假设因果变量是给定的，但现实中我们只有原始数据。

### 2. 可识别性 (Identifiability)

- 什么条件下可以唯一确定因果结构？
- 非线性情况下的可识别性条件？

### 3. 与深度学习的整合

- 如何在神经网络中编码因果归纳偏置？
- 如何端到端学习因果表征？

### 4. 反事实推理 (Counterfactual Reasoning)

- 需要完整的 SCM 模型
- 比干预问题更难，但对智能体至关重要

---

## 关键概念速查

| 概念 | 含义 |
|-----|------|
| **i.i.d.** | 独立同分布假设 |
| **干预 (Intervention)** | 强制设置某个变量的值，记作 do(X=x) |
| **SCM** | Structural Causal Model，结构因果模型 |
| **ICM** | Independent Causal Mechanisms，独立因果机制 |
| **反事实 (Counterfactual)** | "如果当时...会怎样" 的推理 |
